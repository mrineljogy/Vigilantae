# Third-party components

Vigilantae is a local portfolio application maintained in this repository.

- [Streamlit](https://streamlit.io/) provides the interface framework (Apache-2.0).
- [OpenCV](https://opencv.org/) provides the bundled Haar face detector used for photo-only detection and experimental visual comparison (Apache-2.0).
- [Pillow](https://python-pillow.org/) prepares uploaded images (HPND License).
- Python's standard library provides local persistence, password hashing, identifiers, and tests.

The photo comparison feature is an experimental visual aid. It is not an identity determination, forensic tool, official record system, or substitute for human review. No video upload is supported.
